# GuiN（个人生活记忆库）

> 把东西放在哪记下来，需要的时候搜一下就能找到。

GuiN 是一个纯本地、离线运行的 Windows 个人生活记忆库（收纳管理）桌面软件，帮你记住「什么东西放在哪里」。软件名 **GuiN**，使用 DSH 制作，开源，**仅限个人使用**。

**六个要点**

- **纯本地**：所有数据只保存在你自己的设备上，默认不联网、不上传、不需要账号；只有你主动配对的设备之间才会点对点传输数据（端到端加密，不经过第三方服务器中转内容）。
- **记和找都很快**：分类 + 名称 + 存放位置一次录完；顶部搜索框按名称、位置、备注即时过滤。
- **会提醒你**：食品和药品按过期时间提前 30/15/7/1 天提醒（食品、药品分两栏，各自已读/删除），有未读提醒时托盘换成黄色铃铛；便签分「便签」和「提醒便签」两类，提醒便签可以一次性定时，也可以按「每天 / 工作日 / 周六日」循环提醒，到点弹窗、托盘图标闪烁并提示音。
- **数据自己管**：单文件 JSON + 原子写入 + 最近 7 份自动备份；设置页可手动备份（最多 5 份，可覆盖、可还原），还能把 `data.json` 导出 / 导入到另一台设备，退出时自动清理缓存。
- **手机也能用**：同一套功能提供安卓版（手机 / 平板 / 折叠屏自适应界面），直接安装 APK，数据保存在手机本地。
- **两台设备能互通**：手机 ↔ 电脑、电脑 ↔ 电脑可以配对后「发给它 / 从它获取 / 合并」，同步前自动备份、失败自动回滚；手机 ↔ 电脑只同步分类、条目和备注，不同步便签与提醒。

**1.1.8 新增**：电脑端与手机端的到期提醒都改成「只有自己点过『标为已读』的消息才不再提醒」——打开面板看一眼不算已读，关掉面板也不会替你把消息标成已读；未读的、以及手动点「标为未读」的，下次打开软件仍会给出角标与未读样式。手机端的一次性提醒在关掉提醒弹窗（知道了 / 标记完成）时记为已提醒，不会再出现「每次打开 App 都补发一次系统通知」；已经过去超过 1 分钟的提醒也不再重新排系统闹钟。安卓每天 09:00 的到期提醒汇总通知改为只统计未读，未读清零后顺手清掉通知栏里那条汇总通知。手动「标为已读 / 标为未读 / 全部标为已读 / 删除已读」的用法完全不变。手机端的一次性提醒在关掉提醒弹窗时也会记为已提醒，不会再出现「每次打开 App 都补发一次系统通知」；已经过去超过 1 分钟的提醒也不再重新排系统闹钟。安卓每天 09:00 的到期提醒汇总通知改为只统计未读，未读清零后顺手清掉通知栏里那条汇总通知。顺手清理了已经没人调用的旧通知接口。

**1.1.7 新增**：手机端「我的分类」里右下角的加号改为直接新建当前分类的条目，不再弹出「写便签 / 新建提醒 / 新增条目」菜单；首页右下角的加号保持不变，仍是写便签、新建提醒、新增条目三选一。手机物品分类里没填「存放时间」的条目，卡片上会显示「更新 2026-11-17 10:00」这样可读的时间，不再出现一长串 ISO 时间码。手机首页分类区底部去掉了「长按分类卡片可以拖动排序…」的说明文字（长按拖拽照旧可用）。电脑端做了逐屏截图巡检：首页（便签 / 提醒 / 分类）、四个内置分类与自定义分类、各类条目表单、备注、搜索与最近搜索、到期通知两栏、设置页全部卡片（外观 / 系统 / 提醒 / 搜索历史 / 新手引导 / 数据 / 数据同步 / 手动备份 / 关于 / 退出）、导入导出、新建分类、便签与提醒表单、便签详情、分类菜单与删除确认，全部无文字遮挡、无横向溢出，39 项巡检全部通过。

**1.1.6 新增**：手机「保存并导入闹钟」改为跨品牌方案——先识别系统时钟应用，小米 / OPPO / vivo / 华为等静默导入会丢重复规则的机器自动改成「打开时钟确认」，设置页还能手动选「自动识别 / 不打开时钟 / 打开确认」并一键「测试」（1.1.6 起导入循环提醒会预选工作日重复）。手机扫码会跳过默认的长焦 / 微距镜头换回后置主摄，并把变焦拉回 1x，不再出现「扫码调用长焦」；「按存放时间」排序修复了旧版本条目没有存放时间时全部同序的问题（旧条目回退按创建日期排序），同一天存放的条目切升序 / 降序也能看出顺序变化。手机分类页把搜索框与排序条分成两行、排序条始终显示，输入时不再把第一个排序按钮挤掉，也不会再把光标挤到文字最前面。

**1.1.5 新增**：提醒便签卡片改用「每天 / 工作日 / 周六日 + 时间」描述循环规则，不再显示一长串 ISO 时间；「保存并导入闹钟」会把循环规则一起写进系统闹钟（例如工作日 09:30 在系统时钟里就是周一至周五重复）。分类页排序按钮在电脑端和手机端都支持升序 / 降序循环，食品、药品可按过期时间排序，所有分类的条目都能记录「存放时间」。手机扫码绑定改为卡片式取景面板（带取景框、扫描线、手电筒），默认打开后置主摄 1920×1080，画面按比例铺满取景框、不再拉伸。手机端分类长按拖拽补上了触控兼容（长按后拖动更跟手），并修复了若干长按、提醒与表单交互问题。

**1.1.4 新增**：数据同步可以「检测在线」并给已绑定设备加备注（只影响本机显示）；绑定识别以设备 ID + 机器码为准，对方改设备名、换网络或重装后重新绑定都能认回同一台设备。手机扫码绑定默认打开后置主摄像头，预览画面等比完整显示、不被裁剪放大。提醒便签的标题改为必填，保存时可点「保存并导入闹钟」把标题和提醒时间一键写进系统闹钟（与设置里的「精确闹钟」联动）；便签/提醒便签的「+」按钮长按进入该列多选批量删除，长按卡片弹出删除按钮；分类卡片长按可拖动排序（普通分类与「内置 / 置顶」分类各自成组，只在组内互换），并新增「管理」按钮可多选删除分类。

## 安装与运行

> 该目录是 DSH 代理工具的工作区，带有特殊的 ACL / 完整性标签，会让 Chromium 沙箱初始化失败：进程在启动最初期就以 `0x80000003` 退出，表现就是「双击没反应、窗口都看不到」。
> 把安装包 / 便携版复制到工作区之外（桌面、其他盘目录等）再运行，功能完全一致。

### 安装版（推荐）

1. 双击安装包：默认按当前用户安装到 `%LOCALAPPDATA%\Programs\GuiN`，也可在向导里改安装位置）。
2. 安装完成后从桌面快捷方式或开始菜单「GuiN」启动，双击即可打开主界面。

### 免安装版（portable）

1. 把 `release\GuiN-Portable-1.1.8.exe` 复制到工作区之外。
2. 双击它即可直接运行，不需要安装（数据同样写入 `%APPDATA%\guina`）。

### 安卓版（手机 / 平板）

1. 点开安装；系统提示「未知来源」时允许本次安装即可（APK 用项目自签名证书签名，没有上架应用商店）。
2. 首次打开会有引导页；数据保存在应用私有目录，卸载应用会一起删除，重要数据请先在「设置 → 手动备份 / 导出」里备份。
3. 手机与电脑之间互传数据：两端都打开「设置 → 数据同步」，一端点「绑定新设备」生成六位数字，另一端「输入邀请码绑定」或「扫码绑定」后，即可「发送数据 / 获取数据 / 合并数据」。手机 ↔ 电脑只同步分类、条目、备注，不同步便签与提醒。
4. 详细安装、权限、已知差异见 [安卓版说明](docs/安卓版说明.md)。


## 开发环境

需要 Node.js 18+ 与 pnpm。

```bash
pnpm install       # 安装依赖
pnpm dev           # 开发模式（electron-vite dev，界面热更新）
pnpm build         # 构建到 out/
pnpm pack:win      # 构建并打包 Windows 安装版与便携版到 release/
pnpm pack:dir      # 只生成解包目录 release/win-unpacked/
```

其他辅助脚本：

```bash
pnpm typecheck     # TypeScript 类型检查
pnpm test:logic    # 纯逻辑自测（排序/搜索/到期档位等）
pnpm test:e2e      # 自动化端到端自测
pnpm icons         # 由 resources/ 图标重新生成 build/icon.ico
```

## 数据文件位置

数据保存在 Electron 的 `userData` 目录（`app.getPath('userData')`），Windows 下为：

```text
%APPDATA%\guina\        # 目录名沿用旧内部名 guina（升级不丢数据）；Windows 路径不区分大小写
├─ data.json                        # 全部数据：分类、条目、备注、便签、通知、设置、已保存的地点/容器名称
├─ sync-device.json                 # 数据同步的本机身份、设备名与已绑定设备（不含对方数据）
├─ backups\
│  └─ data-20250101-120000-123.json # 最近 7 份自动滚动备份
└─ backups-manual\                  # 设置页「手动备份」保存的备份（最多 5 份）
```

即 `C:\Users\<用户名>\AppData\Roaming\guina`（目录名取自 Electron 应用的内部名 `guina`，没有随显示名 GuiN 改动，因此从旧版本升级时已有数据仍在这里）。

- **原子写入**：每次保存先写 `data.json.tmp-<进程号>-<时间戳>`，`fsync` 后再 `rename` 覆盖 `data.json`，避免写到一半时断电导致文件损坏；程序内保存有约 200ms 防抖，退出前会强制落盘。
- **滚动备份**：每次覆盖前把当前 `data.json` 复制到 `backups/`，只保留最近 7 份，更早的自动删除。
- **自动恢复**：启动时若 `data.json` 读取失败，会按文件名倒序尝试最近的备份文件。
- **查看与迁移**：设置页「数据」卡片显示数据目录、应用版本、备份数量与上次保存时间，并提供「打开数据文件夹」按钮；换电脑时复制整个 `guina` 目录即可。

## 常见问题

**托盘图标看不到？**

Windows 会把不常用的托盘图标折叠进「隐藏的图标」区域：点任务栏右下角的 `^` 展开；想固定的话，把图标拖到任务栏上，或在「设置 → 个性化 → 任务栏 → 其他系统托盘图标」里打开「GuiN」。

**点了关闭窗口，程序没退出？**

默认勾选了「关闭窗口时最小化到托盘」，点 × 只是隐藏窗口，程序继续在托盘运行（便利贴和到期提醒需要它常驻才能按时触发）。想改成直接退出：设置 → 系统 → 关掉「关闭窗口时最小化到托盘」，之后点 × 就会退出。

**怎么真正退出程序？**

右键点击托盘图标，选择「退出 GuiN」。退出后便利贴与到期提醒不再触发。

**重复启动会不会开很多窗口？**

不会。程序有单实例锁，再次启动只会把已有窗口唤出来。

**卸载后数据还在吗？**

安装版卸载默认不删除数据，`%APPDATA%\guina` 会保留；需要彻底清理时手动删除该目录。

**备份怎么用？**

设置 → 数据卡片里有「手动备份」：填名称（默认当前日期时间）点「立即备份」即可；最多保留 5 份，第 6 份会要求你选择覆盖哪一份。点备份行的「还原」会把数据整体回退到那次备份，界面会先确认一次并建议先把当前数据备份一份。自动备份（最近 7 份）在 `%APPDATA%\guina\backups`，手动备份在 `%APPDATA%\guina\backups-manual`。

**怎么和另一台设备同步数据？**

两台设备都打开「设置 → 数据同步」。A 点「绑定新设备」，把六位数字（或邀请文本 / 二维码）给对方；B 点「输入邀请码绑定」或「扫码绑定」，输入六位数字完成绑定。绑定后任选「发给它」「从它获取」「合并」。同步走两台设备之间的点对点加密连接，需要两台设备都能上网；手机 ↔ 电脑只同步分类、条目和备注（不同步便签与提醒），电脑 ↔ 电脑同步全部数据；同步前会自动备份本机数据，失败自动回滚。

**同步连不上怎么办？**

先确认两台设备都装着最新版、都打开着应用并且能上网（部分公司或校园网会限制点对点连接）。同一 Wi-Fi 下成功率最高；仍然失败可以换个网络重试，或者用「设置 → 数据 → 导出 / 导入 data.json」做离线转移。绑定关系只保存在本机，解绑后需要重新绑定。

**手机版和电脑版数据一样吗？**

手机版功能与电脑版一致（分类、条目、备注、便签、提醒、到期通知、备份、同步、导入导出），界面按手机交互重做；手机与电脑之间同步时按需求不同步便签与提醒。两边数据各自独立保存，需要时手动点一次同步。

**点退出后数据会丢吗？**

不会。退出流程会先隐藏窗口与托盘、清掉 Chromium 的缓存，再完全退出；`data.json` 与备份都不动。缓存目录里会留下约 1–2 MB 的 Chromium 固定结构，属正常现象。
